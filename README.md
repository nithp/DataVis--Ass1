# Data Visualization Workshop
This repository contains all the notebooks, and resources used throughout the workshop, where we explore various types of plots using Seaborn, Matplotlib, and Plotly Express. Each day focuses on different types of visualizations, guiding you from basic to advanced techniques.

# Key Learning Outcomes:
Understanding the basics of data visualization.
Mastering different types of plots for data analysis.
Customizing plots for better readability and presentation.

# Tools Covered
Matplotlib: A versatile library for creating static, animated, and interactive visualizations in Python.
Seaborn: A data visualization library based on Matplotlib that provides a high-level interface for drawing attractive statistical graphics.
Plotly Express: A high-level interface to Plotly for creating interactive plots easily and quickly.

# Overview
Over the 6-day Data Visualization Workshop, I gained a comprehensive understanding of creating and customizing a wide range of visualizations using Matplotlib, Seaborn, and Plotly Express. I started with the basics of Matplotlib, including simple plots like line graphs and scatter plots, and progressed to more advanced topics such as bar graphs, pie charts, and subplots. I then explored Seaborn for enhanced statistical graphics, focusing on relational plots like scatter plots, line plots, and pair plots. Finally, I was introduced to Plotly Express for creating interactive visualizations and completed a comprehensive project that integrated all the skills learned to create a dynamic dashboard.
